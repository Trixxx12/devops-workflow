## Branch Naming Convention
- Feature branches: `feature/branch-name`
- Bug fixes: `bugfix/branch-name`
- Hotfixes: `hotfix/branch-name`
- Releases: `release/v1.0.0`

## How to Create a Feature
- Create branch git checkout -b feature/greet_user
- Make changes (I used the vim editor)
- Stage and commit (git add, git commit -m "added greet_user feature"
- Push feature (git push -u origin feature/greet_user)

## How to Sumbit a PR
- Go to github Compare and pull request
- Add title and a fitting PR direct and concise for people to read
- Click "Create Pull Request"
- Squash and Merge when approved
